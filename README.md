Выполнила Пичугина Елизавета М8О-106БВ-26

## Задача

Реализовать Python-пакет с CLI, содержащий:

- **калькулятор арифметических выражений** - поддержка целых и вещественных чисел, операций `+`, `-`, `*`, `/`, унарных `+` и `-`, приоритета `*` и `/` над `+` и `-`, игнорирование пробелов;
- **конвертер единиц измерения** - поддержка групп «длина», «масса», «температура», запрет конвертации между разными группами, запрет температуры ниже абсолютного 0.

### Справка


### Калькулятор

```bash

# 2.5

# 10

```
### Конвертер

```bash

# 10000.0

python -m toolkit convert 1 --from kg --to g
# 1000.0

# 0.5

python -m toolkit convert 0 --from c --to k
# 273.15

python -m toolkit convert 100 --from c --to f
# 212.0

python -m toolkit convert 50 --from f --to c
# 10.0
```

## Калькулятор поддерживает
- Целые и вещественные числа: 1, 1.5, .5.
- Бинарные операторы: +, -, *, /.
- Унарные операторы: -, +.
- Приоритет * и / над + и -.
- Игнорирование пробелов между токенами.
- Целые результаты возвращаются как int, дробные — как float.
- Запрещены два бинарных оператора подряд: 2 * / 2.

Ошибки: пустое выражение, недопустимый символ, пропущенный операнд, два числа подряд, деление на ноль.

---

## Конвертер поддерживает
- Длина: mm, cm, m, km;
- Масса: g, kg;
- Температура: c, f, k.
Правила:
- регистр единиц не учитывается;
- конвертация между разными группами запрещена;
- температура ниже абсолютного нуля запрещена;
- результат возвращается как float.

Ошибки: неизвестная единица, несовместимые единицы, неверное числовое значение, температура ниже абсолютного нуля.

## Алгоритм вычисления
Выражение проходит tokenize() ->  validate() →  parse()  →  результат


Класс Parser реализует рекурсивный спуск
|---|---|
|expr         |самый низкий приоритет (+, -)|
|term         |средний (*, /)               |
|unary        |унарные + и -                |
|primary      |числа (самый высокий)        |

Используемые библиотеки: pytest, argparse, sys
